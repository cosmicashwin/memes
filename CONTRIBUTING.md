# Contributing

Thanks for helping improve this collection!

## Adding an image

1. Add the image to the `Memes/` directory.
2. Use a short, descriptive filename where possible. Keep existing filenames if changing them would lose useful context.
3. Prefer common image formats such as JPG, PNG, or GIF, and avoid adding unrelated files or duplicate copies.
4. If known, include the creator and source in a nearby note or in the pull request description.
5. Only submit material you have the right to share. Do not assume that an image found online is free to redistribute.

## Proposing a change

Open a pull request describing what you added or changed. For image additions, mention the source and any relevant attribution or permission details.
